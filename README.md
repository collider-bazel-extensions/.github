# .github

Organization-wide files for
[collider-bazel-extensions](https://github.com/collider-bazel-extensions):

- `profile/README.md`: the organization's profile page.
- `.github/ISSUE_TEMPLATE/`: the "Request a rules package" issue form.
  GitHub also offers it on every repo in the organization that doesn't have
  its own `ISSUE_TEMPLATE` folder, next to blank issues.

To request a new rules package,
[open a request](https://github.com/collider-bazel-extensions/.github/issues/new?template=request-a-rules-package.yml).
Open requests:
[`label:package-request`](https://github.com/issues?q=org%3Acollider-bazel-extensions+label%3Apackage-request+is%3Aopen)
across the organization.
